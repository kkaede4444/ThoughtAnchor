# 0.1.0 验证记录

2026-10-07，在 Windows 11 x64（系统版本 10.0.26200，200% 显示缩放）验证。Node.js 24.21.0、Electron 44.6.0。

## 已通过

- `npm test`：3 个文件、22 项测试。包含嵌套组合、模板内归组与拆开、吸附决策、原文复用、过渡句失效、导入结构拒绝、长 Unicode 文本、IME 提交判定。
- 存储：20 次并发捕捉逐一保存；重新创建 Store 恢复；损坏主文件回退到备份并保留损坏文件；写入失败不确认保存；之后可继续保存；撤销不会擦掉后来捕捉的闪念或草稿。
- AI：OpenAI 兼容、Anthropic、Gemini 的请求与响应通过模拟适配器检查。拒绝错误排列、重复/未知编号、越界过渡、超过长度的句子、改写字段、截断 JSON、过期建议。请求不跟随重定向，远程地址必须 HTTPS。
- `npm run build`：TypeScript 检查和三部分生产构建通过。
- `npm audit`：开发和运行时依赖均为 0 项已报告漏洞（本次锁文件与审计时间）。
- 真实桌面窗口：中文输入、Enter 保存并继续、拖放归组、折叠组合、组合原文进入成文区、捕捉窗 Esc 收起后恢复草稿、捕捉成功后清空输入。通过 Windows 原生 UI 操作观察。
- 实际 Electron 窗口加载 300 个片段、500 条关系，渲染桥与卡片数量检查通过。这是基本加载检查，不是长时间性能压测。
- 构建 NSIS 安装包和 portable EXE；检查成品可执行文件名称、版本与图标资源。
- 实际 portable EXE 解包后启动：渲染、IPC、全局快捷键注册、托盘图标、捕捉持久化、独立捕捉窗标题均通过，输出截图和检查结果。
- 发布文件检查：源码 ZIP 对照 Git 文件清单；安装包资源对照构建范围，未包含本机思路数据、捕捉草稿、密钥文件或开发检查目录。Git 提交使用 GitHub noreply 地址，避免公开常用邮箱。

## 验证边界

没有调用付费 AI 接口，没有验证真实厂商账号的额度、地区权限与当前模型可用性。中文输入法的组合状态通过事件判定测试，未逐一人工测试各厂商输入法。

安装包已构建，未执行完整的 Windows 10 实机安装/卸载流程；没有付费代码签名。没有多人同步、云账户、图片附件或自动 AI 调用，这些均不在首版范围内。

Markdown 导出的原生保存对话框已打开检查，写出文件的人工验证尚未完成。

流畅程度、奖励感和心流效果需要真实使用反馈；这里的工程检查不代表主观体验已经得到证明。

GitHub CI 会在推送与 Pull Request 中运行检查，版本标签触发 Windows 构建。已有 Release 保留已发布的文件，云端构建另存为工作流产物。本机验证与云端 CI 状态分别记录。
