# ThoughtAnchor 视觉方向

主参考：[Anthropic — Scenarios for our Economic Future](https://www.anthropic.com/institute/econ-scenarios)。
辅助参考：[Anthropic 官网](https://www.anthropic.com/) 的排版、留白与阅读节奏。

## 整体感受

把白板做成一张暖白的纸，想法是留在纸上的片段，颜色来自水彩与画笔。界面应温暖、安静、有触感，手动拼接时能看到明确的小变化。

采用原创的纸纹、笔触与图示。参考页中的图表可见颗粒、不均匀覆盖、轻微叠色和手画格线；这些特征共同决定风格，不能仅以浅色渐变代替。

| 暖白纸面     | `#FAF9F5` |
| 正文墨色     | `#292822` |
| 次要文字     | `#76736A` |
| 纸边与分隔线 | `#DCD8CD` |
| 陶土笔触     | `#BF765B` |
| 鼠尾草       | `#97A77F` |
| 淡紫         | `#AFA0CB` |
| 雾蓝         | `#87A9CE` |
| 灰玫瑰       | `#CC96A6` |

颜色作为可调的颜料基色，渲染时叠加局部深浅与透明度。正文使用稳定的深色文字；画笔质感集中在纸面、色块、连接线、边缘和反馈。

中文标题与卡片正文使用清晰的宋体风格，工具栏、控件和辅助信息使用易读的无衬线字体。正式桌面版本应提供许可允许打包的本地字体，使离线排版稳定。

## 拼图工作台

- 背景是略粗糙的纸面，格线较淡，线条轻微不规则；纸纹使用固定种子生成。
- 文字块有稳定的文字区域，颜料覆盖可以不均匀，边缘保留轻微晕染。笔触不影响文字排版或拖放命中区域。
- 归组外框像画笔轻轻圈住几片纸，组合标题和连接线保持清晰。
- 拼接落点与成功反馈使用一次短促的描绘、收笔或印记，反馈对应实际结构变化。
- 布局沿用官网的宽松留白和简洁控件，密集内容仍以可读性为先。

## 渐次落笔的加载图示

- 三片半透明水彩块通过手画曲线连接，沿路径依次显现；颜料具有细颗粒、深浅过渡和轻微叠色。
- 默认约 3.8 秒完成一个柔和周期：先落笔，逐步铺色，再短暂停留并淡出；三片错开出现。
- 等待期间可循环，实际加载结束即停止；没有真实进度时不展示百分比。
- 图示体积和动画局限在加载区域，正文与工具栏保持稳定。
- 支持减少动态效果：显示完整的静态图示和等待文字，屏幕阅读器只接收实际状态变化。

## 本次样板

对话中的视觉样板包含拼图工作台、归组/拆开演示、加载图示、重播与暂停，以及纸纹、水彩浓度和落笔节奏的调节。

正式实现：`src/renderer/src/Art.tsx` 与 `src/renderer/src/style.css`；图标源码位于 `build/icon.svg`。

它用于确认视觉与动画方向；正式桌面软件的捕捉、存储、吸附规则和 AI 接入沿用已讨论的产品计划。
