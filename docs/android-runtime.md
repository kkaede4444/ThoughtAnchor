# Android、触控与局域网同步

0.4.1 的 Android 应用使用 Kotlin 原生容器和系统 WebView。手机、平板与 Windows 共用文档规则和界面资源；文件、密钥、HTTP、配对与持久化由各平台原生层处理。界面没有文件访问权限，也不能读取密钥。macOS/iOS 尚未生成安装包，后续可实现同一原生消息接口。

## 界面与画笔

自动模式按设备类型选择：Android 最小屏幕宽度至少 600 dp 为平板，使用 PC 三栏工作台；手机使用白板、闪念、成文三个页面。设置中的移动／桌面模式覆盖自动选择，保存在本机，不参与同步。旋转屏幕保持所选模式。

手机点击左上角或从左侧应用内边缘／标题区域右划打开目录；左侧系统返回手势仍由 Android 处理。目录位于白板上层，背景缩小、平移与模糊。底部提供新建思路纸和设置入口。系统返回键依次关闭设置、目录、编辑等页面。

所有设备的白板左下角都有移动、画笔、橡皮擦。画笔支持颜色、四档粗细、触控笔压力；移动模式下触控笔可直接书写，手指继续平移。手指或鼠标绘画需主动切换画笔。橡皮擦删除触及的整条笔迹，一次手势可撤销。双击画布／双击触摸在当前和上一次工具间切换，例如画笔 → 橡皮擦后双击回到画笔，再双击回到橡皮擦。移动画布和框选也参与工具历史；双击文字编辑仍保留。识别双击时不会留下误画的点或误擦笔迹，单点落笔等待短暂双击识别窗口后自动保存。笔迹使用白板世界坐标，跟随缩放和平移，不改写片段、连接或成文。

笔迹进入 `.thoughtanchor` v3 导出和本地保存；仍可读取 v1/v2，没有笔迹的导出保持 v2。首次本地写入 v3 时额外保留 `workspace.v2-backup.json`。旧版本不支持 v3 文件。

设置提供“直接在卡片上绘制”，默认关闭，旧数据升级也保持关闭。开启后，画笔在卡片正文落下会保存到这张卡片，每笔自动保存；橡皮擦删除该卡片中触及的整条笔迹，一次手势可撤销。卡片文字和尺寸保持原样，笔迹在卡片内裁切，空白处仍写入白板。该开关仅保存在本机，不随同步改变。关闭后，卡片绘图仍通过小窗完成。

卡片标题右侧的画笔打开卡片绘图小窗；手机也可选中卡片后使用底部绘图按钮。小窗显示卡片原有文字、纸面和已有笔迹，文字下方额外预留至少 180 像素的空白绘图区域；这是小窗的绘图空间，不会自动放大原卡片。小窗内还可设置卡片宽高，点击保存时与绘图一起保存，取消则都不改变。提供颜色、粗细、擦除和本次编辑的撤销／重做；工作台撤销可撤回整个保存，包括尺寸。绘图随卡片分组、移动、导出和同步，重开编辑器可继续修改。同期卡片绘图或准备修改的尺寸改变时拒绝覆盖，需重新打开。AI 成文及 Markdown／纯文本只处理卡片文字，矢量绘图保存在思路纸文件中。

## 同一局域网配对

Windows 设置中开启局域网同步并生成五分钟有效的配对码。Android 设置可以扫码或粘贴配对链接。Windows 运行期间在局域网 TCP 43871 接收同步，UDP 43872 提供已配对主机发现；防火墙需允许应用在所在局域网接收入站连接。Windows 关闭同步或撤销配对后不再接受对应设备。

配对链接含随机设备凭据和 Windows TLS 证书指纹，请只在自己的设备使用。Android 固定校验已配对证书，传输使用 TLS 1.2。Windows 凭据与证书使用当前用户 DPAPI 加密，Android 使用 Android Keystore AES-GCM 加密。没有云中继。

同步范围是思路纸（片段、分组、关系、笔迹、独立稿件）、全局收件盒，以及语言、写作选项、接口地址／协议／模型。密钥、设备界面模式、视野、快捷键、音效与快速捕捉草稿不参与。首次连接采用电脑的通用设置。共同基线支持删除和离线编辑；同一纸双端修改时保存两份，重试不重复复制。双方修改通用设置时手机设置显示选择本机／电脑设置的入口。

前台每五秒检查同步，断线后继续在本地保存；回到应用后自动重试。后台 WorkManager 在不限流量网络上尽力执行周期同步，周期下限十五分钟，实际时机由系统决定。没有常驻前台服务和常驻通知。电脑休眠、应用退出、网络隔离或防火墙阻止时无法同步。

## 本地文件与构建

Android 数据位于应用私有目录，主文件原子替换并保留两份最近备份。文件导入／导出使用系统文件选择器；其他应用可通过“分享文本”把内容放入闪念收件盒。API 请求由原生层按按钮触发，每阶段最多六十秒；取消会关闭当前连接。

需要 Node 24、JDK 17 或 21、Android SDK 平台与构建工具 36。设置 `JAVA_HOME`、`ANDROID_HOME` 后运行：

```sh
npm ci
npm run build:android
npm run test:android
```

构建输出 `release/ThoughtAnchor-0.5.0-android.apk` 和 SHA-256。首次构建自动创建本地发布签名，保存在被 Git 忽略的 `.local/android-signing`，请私下备份整个目录；后续更新必须使用同一签名。此目录和密钥不得提交或包含在发布文件中。

`test:android` 需要已授权 USB 调试的手机和已构建的 Windows 原生 EXE。它使用独立 `.test` 包和 Windows 临时目录，清空的仅是测试包。检查前台手势、笔迹、重启恢复、实际 Wi-Fi TLS 同步与离线冲突；AI 只调用本机模拟服务。平板布局使用同一手机的 Chromium 尺寸与设备类型模拟，不能代表真实平板触控笔或掌触拒绝的验收。
