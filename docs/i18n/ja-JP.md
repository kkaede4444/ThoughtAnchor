# ThoughtAnchor

[言語一覧](../README.md) · [Windows / Android をダウンロード](https://github.com/kkaede4444/ThoughtAnchor/releases/latest)

ThoughtAnchor は Windows と Android 向けのローカル中心の思考ボードです。断片を保存し、カード、グループ、線、手描きで整理して、元の文章を使った記事にまとめます。紙の質感、水彩、セリフ体を各端末で共有します。

自分自身と ADHD のある人が、散らばる考えを少ない負担で整理できる場所を作りたくて、ThoughtAnchor を始めました。浮かんだ考えをまず残し、余力がある時に少しずつ並べたりつなげたりします。整理に使う忍耐を減らし、考えそのものに注意を向け、フローに入りやすくすることが目標です。原文を再利用し、取り消しながら、自分のペースで進められます。

本プロジェクトは、管理者が示した要件と方向性に基づき、実装、画面、テスト、文書、パッケージ作成まで **Codex が全面的に構築**しました。第三者の部品にはそれぞれのライセンスが適用されます。[MIT ライセンス](../../LICENSE)により、事前の許可なく利用、変更、再配布、商用利用できます。著作権表示と許諾文を残してください。ソフトウェアは現状のまま提供されます。

## インストールと使い方

- Windows 10/11 x64：インストーラー、ポータブル EXE または ZIP を選びます。ZIP は展開後 `ThoughtAnchor.exe` を起動します。WebView2 Runtime と .NET Framework 4.8 が必要です。ウィンドウを閉じてもトレイに常駐します。終了はトレイから行います。Windows 版はコード署名されていません。
- Android 8.0 以降：APK をインストールし、システム WebView を更新してください。スマートフォンはモバイル画面、タブレットはデスクトップ画面が既定です。設定で切り替えられます。現在の配布対象は Windows と Android です。
- Release の `SHA256SUMS.txt` とダウンロードしたファイルのハッシュを照合してください。

受信箱は Enter で保存、Shift+Enter で改行。Windows では起動中に `Ctrl+Shift+Space` で素早くメモできます。カードをボードに移し、ドラッグ、四辺の端子での接続、グループ化を行います。文字はダブルクリックで編集。選択したカードやグループを記事欄に追加し、順序を調整します。

移動、選択、ペン、消しゴムは前のツールを記憶します。ボードをダブルクリック／ダブルタップすると前のツールに戻り、もう一度で切り替え直せます。Windows の取り消し／やり直しは `Ctrl+Z` / `Ctrl+Y`。カードの描画ウィンドウには全文と下の余白が表示され、幅と高さも変更できます。保存はサイズと筆跡を一緒に確定し、キャンセルは破棄します。カードへの直接描画は **既定でオフ**。有効時は一筆ごとに保存します。

スマートフォンでは右スワイプか目次ボタンでサイドバーを開き、下部から設定に進みます。LAN 同期は同じ到達可能なネットワークと起動中の Windows が必要です。Windows のペアリングコードを Android で読み取るか貼り付けます。オフラインの競合は両方のボードを保存。キーと端末固有設定は同期しません。ボードは `.thoughtanchor`、記事は Markdown／テキストで書き出せます。読み込みはコピーを作成します。定期的にバックアップしてください。

## 任意の AI とプライバシー

ボードにはキーが不要です。設定に GLM、Kimi、Qwen、MiMo、MiniMax、Grok、Tencent Hunyuan と従来のサービスがあります。サービス、ベース URL、モデル、対応するキーを設定します。地域と JSON の詳細は [API 設定](../providers.md) を参照。組み立ては原文を保ち、推敲は別の下書きを作ります。採用するまでプレビューで、カードは上書きしません。

AI ボタンを押した時だけ必要な現在の記事／下書きを送信します。キーは DPAPI／Android Keystore で暗号化し、書き出しや同期には含めません。テレメトリーやホスト型クラウド同期はありません。書き出しファイルは平文です。[安全性](../../SECURITY.md) · [検証範囲](../verification.md)。有料 API の実呼び出しは検証していません。

## 開発

Node.js 24 LTS を使用。Windows は上記環境、Android は JDK 21 と SDK 36 が必要です。[Android 手順](../android-runtime.md)。

```sh
npm ci
npm test
npm run security
npm run package
npm run build:android
```

出力は `release/`。Android の署名秘密鍵は更新のために保持し、コミットしないでください。隔離データでの回帰確認：`npm run test:native` / `npm run test:android`。[構成](../native-runtime.md) · [第三者ライセンス](../third-party-notices.md)。
