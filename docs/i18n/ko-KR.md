# ThoughtAnchor

[언어 목록](../README.md) · [Windows / Android 다운로드](https://github.com/kkaede4444/ThoughtAnchor/releases/latest)

ThoughtAnchor는 Windows와 Android용 로컬 중심 생각 보드입니다. 떠오른 생각을 저장하고 카드, 그룹, 연결선, 그림으로 정리한 뒤 원문을 활용해 글을 만듭니다. 따뜻한 종이색과 수채화, 세리프 글꼴을 모든 기기에서 사용합니다.

저 자신과 ADHD가 있는 사람들이 흩어진 생각을 더 적은 부담으로 정리할 수 있도록 ThoughtAnchor를 시작했습니다. 생각이 떠오르면 먼저 남기고 여유가 생길 때 조금씩 배치하고 연결합니다. 정리에 쓰는 인내를 줄여 생각 자체에 주의를 더 기울이고 몰입에 들어가기 쉽게 만드는 것이 목표입니다. 원문을 재사용하고 언제든 실행을 취소하며 자기 속도로 진행할 수 있습니다.

관리자가 요구사항과 제품 방향을 제시하고, **Codex가 이 프로젝트 전체를 구축**했습니다. 구현, 화면, 테스트, 문서, 패키징이 포함됩니다. 외부 구성 요소는 각 라이선스를 유지합니다. [MIT 라이선스](../../LICENSE)에 따라 사전 허가 없이 사용, 수정, 재배포, 상업적 이용이 가능합니다. 저작권 및 라이선스 고지를 유지해야 하며 소프트웨어는 있는 그대로 제공됩니다.

처음 사용할 때 여덟 가지 언어를 선택하는 화면이 열리며 시스템 언어가 미리 선택됩니다. 시작하기를 누르면 선택한 언어로 된 산책 예시의 제목, 카드 세 장과 연결 설명이 있는 보드가 열립니다. 나중에 설정에서 화면 언어를 바꿀 수 있지만 저장된 메모의 원문은 유지됩니다. 기존 사용자가 업데이트할 때는 다시 표시하지 않습니다.

## 설치 및 사용

- Windows 10/11 x64: 설치 프로그램, portable EXE 또는 ZIP을 받습니다. ZIP은 압축을 풀고 `ThoughtAnchor.exe`를 실행합니다. WebView2 Runtime과 .NET Framework 4.8이 필요합니다. 창을 닫으면 트레이에 남으며 트레이 메뉴로 종료합니다. Windows 파일은 코드 서명되지 않았습니다.
- Android 8.0 이상: APK를 설치하고 시스템 WebView를 최신 상태로 유지하세요. 휴대전화는 모바일 화면, 태블릿은 데스크톱 화면이 기본입니다. 설정에서 변경할 수 있습니다. 현재 Windows와 Android 패키지를 제공합니다.
- Release의 `SHA256SUMS.txt`와 다운로드 파일의 해시를 비교하세요.

수신함에서 Enter는 저장, Shift+Enter는 줄바꿈입니다. Windows 앱 실행 중 `Ctrl+Shift+Space`로 빠른 메모를 엽니다. 카드를 보드로 옮겨 드래그하고 네 면의 연결점으로 연결하거나 그룹화합니다. 글을 두 번 클릭하면 편집합니다. 선택한 카드/그룹을 글 영역에 추가하고 순서를 정하세요.

이동, 선택, 펜, 지우개는 이전 도구를 기억합니다. 보드를 두 번 클릭/탭하면 이전 도구로 돌아가며 다시 두 번 누르면 재전환됩니다. Windows 실행 취소/다시 실행은 `Ctrl+Z` / `Ctrl+Y`입니다. 카드 그림 창은 전체 글과 아래 여백을 보여주며 너비/높이도 변경할 수 있습니다. 저장하면 그림과 크기가 함께 적용되고 취소하면 둘 다 버립니다. 카드 직접 그리기는 **기본적으로 꺼짐**이며 켜면 획마다 자동 저장합니다.

휴대전화에서는 오른쪽으로 밀거나 목차 버튼으로 사이드바를 엽니다. 설정은 아래쪽에 있습니다. LAN 동기화에는 같은 연결 가능한 네트워크와 실행 중인 Windows 앱이 필요합니다. PC의 페어링 코드를 Android에서 스캔하거나 붙여넣으세요. 오프라인 충돌 시 두 보드를 모두 보존합니다. 키와 기기별 설정은 로컬에 남습니다. 보드는 `.thoughtanchor`, 글/초안은 Markdown 또는 텍스트로 내보낼 수 있습니다. 가져오기는 복사본을 만듭니다. 정기적으로 백업하세요.

## 선택적 AI 및 개인정보

보드에는 키가 필요 없습니다. 설정은 GLM, Kimi, Qwen, MiMo, MiniMax, Grok, Tencent Hunyuan 및 기존 서비스를 지원합니다. 제공업체를 고르고 필요한 기본 URL/모델과 해당 플랫폼 키를 저장하세요. 지역별 주소와 JSON 설정은 [API 안내](../providers.md)를 참조하세요. 조합은 원문을 보존하고 다듬기는 별도 초안을 만듭니다. 채택 전에는 미리보기이며 카드를 덮어쓰지 않습니다.

AI를 직접 실행할 때만 필요한 현재 글/초안을 전송합니다. 키는 DPAPI 또는 Android Keystore로 암호화하며 내보내기/동기화에 포함하지 않습니다. 텔레메트리나 호스팅 클라우드 동기화는 없습니다. 내보낸 파일은 읽을 수 있는 평문입니다. [보안](../../SECURITY.md) · [검증 범위](../verification.md). 유료 API 실호출은 검증하지 않았습니다.

## 개발

Node.js 24 LTS를 사용합니다. Windows는 위 환경, Android는 JDK 21과 SDK 36이 필요합니다. [Android 설정](../android-runtime.md).

```sh
npm ci
npm test
npm run security
npm run package
npm run build:android
```

결과는 `release/`에 저장됩니다. 업데이트를 위해 Android 서명 개인 키를 보관하고 커밋하지 마세요. 격리 데이터로 실행하는 회귀 검사: `npm run test:native` / `npm run test:android`. [구조](../native-runtime.md) · [외부 라이선스](../third-party-notices.md).
